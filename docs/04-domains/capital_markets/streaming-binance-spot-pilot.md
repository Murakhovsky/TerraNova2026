# Пілот Binance Spot BBO

Цей інкремент підключає одне котирування через публічний WebSocket Binance до наявної системи Capital Markets. Це ще не готовий промисловий сервіс та не реалізація синхронізації ордербука.

## Умови запуску

Перед запуском необхідно перевірити SQL-міграцію оренди потоку, зареєструвати активне джерело Binance Spot, створити рівно одну активну підписку типу BBO та пов'язати інструмент із торговим майданчиком.

Додатково повинні бути ввімкнені відповідні прапорці домену, ринкових даних, Binance та потокового режиму. Окремий запобіжник оператора: змінна `COS_CM_STREAMING_BINANCE_SPOT_PILOT=1`.

Приклад командного запуску:

```bash
COS_CM_STREAMING_BINANCE_SPOT_PILOT=1 php symfony/bin/console cos:capital-markets:market-data:stream:binance-spot ORG_ID SOURCE_ID --seconds=60
```

Потік проходить через реєстр підписок, підтвердження Binance, перевірку десяткових значень, формування `RawMarketEvent`, блокування lease та канонічне приймання даних.

Ідентифікатор оновлення `bookTicker` зростає, але **не є** послідовним номером дельт ордербука. Його не можна використовувати для доведення цілісності L2.

## Обмеження пілота

Підтримується один BBO-інструмент для одного джерела. Поки відсутні перевірені багатосимвольні підписки, відновлення L2, автоматичне перепідключення після збою, незалежний контроль протермінованого lease та завершені інтерфейси оператора.

Наявний REST-опитувач може одночасно оновлювати стан того самого інструмента. Перед промисловим використанням потрібно усунути цей конфлікт.

Не проведено повний інтеграційний тест із MySQL та реальним біржовим потоком і тривале тестування стійкості. Живу торгівлю заборонено, потоковий режим за замовчуванням вимкнено.
