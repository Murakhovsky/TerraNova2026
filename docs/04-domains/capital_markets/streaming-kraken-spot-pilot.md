# Пілот потокових даних Kraken Spot і xStocks

Використовується публічний канал WebSocket v2 `ticker` з параметрами `event_trigger=bbo` та `snapshot=true`. Він передає найкращі ціни купівлі й продажу, **не повний ордербук L2**.

У налаштуваннях FOS необхідно попередньо створити відповідний інструмент, майданчик, торгову пару та одне активне підписання BBO. Назву пари беремо **тільки з реального зіставлення Kraken**, тому система не припускає, що будь-яка акція має певне позначення xStocks або доступна в конкретній юрисдикції.

## Перевірка подій

Після підключення система очікує підтвердження підписки зі збігом символу й номера запиту, далі початковий snapshot. Кожне котирування проходить перевірку символу, часу RFC3339, чотирьох числових значень та збереження десяткової точності. Числа з JSON конвертуються в текстові десяткові значення **без переходу через float**.

Події зі старішим часом або зміненою ціною при однаковому часі скидають сесію, після чого потрібні перепідключення й новий snapshot. Події heartbeat і status підтверджують активність каналу, але не оновлюють ринкову ціну.

## Запуск пілота

Потрібні прапорці домену, ринкових даних, Kraken і streaming, а також додатковий запобіжник `COS_CM_STREAMING_KRAKEN_SPOT_PILOT=1`.

```bash
COS_CM_STREAMING_KRAKEN_SPOT_PILOT=1 php symfony/bin/console cos:capital-markets:market-data:stream:kraken-spot ORG_ID SOURCE_ID --seconds=60
```

## Невиконані вимоги

Це пілот одного BBO-інструмента на джерело. Ще не готові багатосимвольні потоки, повне відновлення книги заявок, підключення фондового underlying через Massive, незалежний sweeper для Kraken, автоматичне керування робочими процесами та production soak.

Без перевірки точних торгових пар та прав використання біржових даних пілот не можна вважати промислово готовим. Жива торгівля залишається вимкненою.

Документація провайдера: https://docs.kraken.com/exchange/api-reference/spot-websocket-v2/ticker
