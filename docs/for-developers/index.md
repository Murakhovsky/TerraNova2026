## Архітектурний принцип

COS розділяє предметну логіку бізнесу та загальні механізми виконання. Домен володіє бізнес-смислом, а Kernel і Platform надають універсальні механізми виконання, подій, правил, політик, інтеграцій, розширень і спостереження.

## Перед зміною коду

Визначте:

- хто семантично володіє новою поведінкою;
- який бізнес-процес або use case змінюється;
- які дані та переходи стану зачіпаються;
- які зовнішні контракти змінюються;
- які наслідки є для tenant isolation та authorization;
- які тести доводять нову поведінку.
